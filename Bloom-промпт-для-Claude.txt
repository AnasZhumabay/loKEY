Привет! Помоги мне запустить приложение Bloom на этом компьютере с Windows и дальше работать с ним вместе.

## Что такое Bloom
Bloom — программа для авторов коротких видео (Instagram Reels, TikTok, YouTube Shorts): идеи, сценарии с хуками, подписи и хэштеги, календарь публикаций, аналитика. Друг прислал мне архив: Bloom-Setup-2.0.0.zip (установщик) или Bloom-Windows-portable-2.0.0.zip (без установки). Скорее всего, он лежит в папке «Загрузки».

Bloom хранит всё в папке %USERPROFILE%\Documents\Bloom:
- profile.json — кто я, о чём аккаунт, аккаунты на платформах;
- projects\<id>.json — один файл на проект;
- README.md — описание формата файлов (Bloom создаёт его при первом запуске).
Bloom проверяет папку каждые 2 секунды: если ты запишешь туда файл, он сам появится в приложении.

Кнопки «Придумать идеи» и «Написать сценарий» внутри Bloom запускают тебя (команду claude) без инструментов, просто текст запроса и ответ. Поэтому мне нужен рабочий Claude Code, в который я вошёл своим аккаунтом.

## Шаг 1. Запуск
1. Найди архив Bloom в «Загрузках» и распакуй его.
   - Если это Bloom-Setup: запусти Bloom-Setup-2.0.0.exe. Предупреди меня, что Windows покажет «Система Windows защитила ваш компьютер» (у приложения нет платной подписи): нужно нажать «Подробнее» → «Выполнить в любом случае». Установку я подтвержу сам.
   - Если это portable: распакуй в %USERPROFILE%\Documents\Bloom-app и скажи, где лежит Bloom.exe.
2. Узнай полный путь к команде claude (например, where.exe claude). Запиши его мне: если Bloom не найдёт Claude сам, я вставлю этот путь в Настройки Bloom (шестерёнка внизу слева или Ctrl+,).
3. Попроси меня один раз открыть Bloom, чтобы он создал папку Documents\Bloom, и проверь, что папка появилась.

## Шаг 2. Профиль
Спроси меня по одному вопросу:
- о чём мой аккаунт (тема) и для кого (аудитория);
- мои ники в Instagram, TikTok, YouTube и сколько сейчас подписчиков;
- снимаю ли я себя в кадре или всё делается с ИИ (закадровый голос, ИИ-видео).
Потом прочитай Documents\Bloom\README.md и запиши Documents\Bloom\profile.json:
{"name": "...", "niche": "...", "audience": "...", "bio": "...", "faceless": true или false,
 "accounts": {"instagram": {"handle": "ник", "followers": 0, "history": [{"date": "ГГГГ-ММ-ДД", "count": 0}]}, "tiktok": {...}, "youtube": {...}}}
Не теряй accounts.*.history, если файл уже есть.

## Шаг 3. Создай себе скилл для работы с Bloom
Создай файл %USERPROFILE%\.claude\skills\bloom\SKILL.md, чтобы в следующих разговорах ты сам знал, как работать с Bloom. Содержимое:

---
name: bloom
description: Положить проект (видео, карусель, сторис, пост) для Instagram, TikTok или YouTube Shorts, идеи или профиль в приложение Bloom. Используй, когда пользователь просит сделать Reels/TikTok/Shorts, карусель, подпись, сторис, идеи для постов, серию роликов, обновить подписчиков или отметить пост опубликованным.
---
# Bloom — студия коротких видео
Bloom читает папку %USERPROFILE%\Documents\Bloom и сам обновляется через 1–2 секунды после записи файла. Платформы: instagram, tiktok, youtube (Shorts).
- profile.json: автор (name, bio, niche, audience, link, faceless) и accounts по платформам.
- projects\<id>.json: один файл на проект. id: ГГГГММДД-краткое-имя латиницей.
- Формат всех полей: Documents\Bloom\README.md. Прочитай его перед первой записью.

Правила:
1. Пиши на языке аккаунта (по умолчанию по-русски), живым разговорным языком, без канцелярита и без «Привет всем», «Сегодня я расскажу», «Не листай».
2. Поля проекта:
   - kind: reel | carousel | story | post. story только в Instagram, в Shorts только reel.
   - status: idea (только тема), draft (в работе), ready (можно выкладывать).
   - platforms: куда идёт проект.
   - pillar: рубрика из 1–3 слов. style: один из educational, trend, absurd, fiction, mystery, myth, top, character, hotTake, emotional, comedy, satisfying, facts, creepy. Если просят несколько идей, делай их в разных стилях. Вымысел можно только в стилях-историях (absurd, fiction, character, comedy, creepy), факты не выдумывай.
   - angle: одна фраза, чем идея отличается от тысячи похожих.
   - hook: {"text": "...", "formula": "..."}; formula — название одной из 26 формул (Nobody Tells You, Negative Command, The Statistic, The Reveal, Mid-Sentence Start, Contrarian Flip, The Superlative и др.). score не ставь: Bloom сам оценит хук. altHooks — ещё 2 хука.
   - onScreen: текст на экране в первом кадре, до 7 слов.
   - beats: [{"at": "0:00", "label": "ХУК", "text": "фраза (описание кадра в скобках)"}, ...]; первая строка — лучший хук, последняя с label "ПРИЗЫВ" и повторяет слово из хука. Строка не длиннее 9 слов (~4 секунды). Ролик 20–45 секунд.
   - slides: для каруселей, 6–9 слайдов.
   - copies: {"instagram": {"caption", "hashtags"}, "tiktok": {...}, "youtube": {"title" до 100 символов, "caption", "hashtags"}}. Хэштеги без #: Instagram и TikTok до 5, Shorts до 3.
   - notes: советы по съёмке. created: сегодняшняя дата ГГГГ-ММ-ДД.
   - Серия: series (название), part (номер), partsTotal (всего частей); каждая часть, кроме последней, заканчивается крючком на следующую.
3. Не выдумывай цифры и истории от имени автора: ставь {{твоё число}}.
4. Если в profile.json "faceless": true (автор не снимает себя), сценарий — закадровый голос, а в скобках описание кадра для ИИ-генератора видео, без лица автора.
5. Чтобы изменить проект, прочитай файл и перепиши его целиком, сохранив id, created, stats, publishedOn.
6. Ничего не публикуй сам: пользователь копирует текст из Bloom и выкладывает.
После записи коротко скажи, где проект появился в Bloom: в «Идеях» или в «Проектах», и для каких платформ.

Создай одну тестовую идею по теме моего аккаунта (status "idea") и попроси меня посмотреть, появилась ли она в Bloom в разделе «Идеи». Если не появилась — разберись почему (путь к папке, ошибка в JSON).

## Шаг 5. Lemo-Opuscar — чтобы снимать готовые видео
Lemo-Opuscar (github.com/lemomo-ai/lemo-opuscar) — набор из ~100 стилей анимации: ты пишешь код анимации, озвучку и собираешь готовый вертикальный ролик (mp4). Установи его:
1. Проверь, что есть Node 20+, ffmpeg 7+, Python 3.11+ и Git для Windows (node -v, ffmpeg -version, python --version, git --version). Чего нет — поставь через winget (например: winget install OpenJS.NodeJS.LTS, winget install Gyan.FFmpeg, winget install Python.Python.3.12, winget install Git.Git). Git нужен потому, что режиссёр в Киностудии выполняет команды через Git Bash. Каждую установку сначала покажи мне и дождись моего «да». После установки открой новое окно терминала, чтобы обновился PATH.
2. Установи плагин Claude Code:
   claude plugin marketplace add lemomo-ai/lemo-opuscar
   claude plugin install lemo-opuscar@lemolab
3. При первом использовании он сам скачает гайды, инструменты и стили в %USERPROFILE%\lemo-opuscar. Проверь, что папка появилась и в ней есть AGENTS.md и styles.
   Потом поставь голосовые инструменты библиотеки (скрипт setup из plugin\skills\lemo-opuscar\scripts с аргументами deps voice; на Windows запускай его через Git Bash). Bloom проверяет, что есть %USERPROFILE%\lemo-opuscar\.venv\Scripts\python.exe и edge-tts.exe. Если setup не работает на Windows, создай .venv сам: python -m venv .venv, затем .venv\Scripts\pip install edge-tts и остальное, что просит библиотека.
   Проверь в Bloom: Настройки → Киностудия должно показать «Lemo-Opuscar найден: N стилей», а раздел Киностудия — без надписи «Не хватает».
4. Сделай пробный короткий ролик (10–15 секунд) по одному из проектов Bloom в любом стиле, чтобы убедиться, что всё работает на Windows. Готовое видео положи в Documents\Bloom\exports\<название проекта> · <стиль> · <4 символа id>\film.mp4 и скажи мне, где оно.
Если что-то из инструментов Lemo-Opuscar не заработает на Windows, скажи мне честно, что именно и почему, и предложи обходной путь.
В Bloom 2.0 для Windows есть раздел «Киностудия»: там фильмы снимаются кнопкой «Снять фильм» (выбор стиля, голоса, очередь, ночная смена, правки, варианты на других языках, загрузка на YouTube). Если что-то там падает, открой папку фильма в Documents\Bloom\exports и лог ошибки и помоги разобраться.
Ещё в проекте на вкладке «Производство» есть быстрая сборка видео без Lemo-Opuscar: озвучка + субтитры + текст на экране (нужны ffmpeg и edge-tts).
